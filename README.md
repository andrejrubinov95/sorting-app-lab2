# Информационная система «Алгоритмы сортировки»

Практическое занятие №2, вариант 7. Консольное Python-приложение, которое использует алгоритмы сортировки, подключённые в виде отдельного Git-подмодуля `algorithms`.

## Запуск

После подключения подмодуля:

```bash
python main.py --demo
python main.py
python -m unittest discover -s tests -v
```

При клонировании из GitHub:

```bash
git clone --recurse-submodules URL_ПРОЕКТА
```

Для существующей копии:

```bash
git submodule update --init --recursive
```

Поддерживаются числа с отрицательными значениями, повторами и нулём. Список доступных алгоритмов зависит от версии подключённого подмодуля. Программа проверяет корректность результата относительно встроенной сортировки Python.

Проект не использует внешние библиотеки: нужен только Python 3.10+.
